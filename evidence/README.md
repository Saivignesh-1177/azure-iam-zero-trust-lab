# Evidence

This directory is intentionally empty until the lab is executed.

## Evidence Rules

Only store evidence produced by an actual test or deployment.

Recommended evidence:
- CLI output (`.txt`)
- redacted JSON configuration exports (`.json`)
- screenshots (`.png`)
- test output (`.txt`)
- query results (`.csv`)
- hashes of important artifacts (`SHA256SUMS.txt`)

Never commit:
- passwords
- access tokens
- client secrets
- private keys
- tenant-sensitive data
- personal information
